输入文件  : full_frame_camera.h264
Codec     : H.264
分辨率    : 1920x1080
帧率      : 30 fps
SPS/PPS   : 自动提取 (30 bytes / 4 bytes)

配置文件
───────────────────────────────────────────────────────────────────────────────
[video]
file      = sim_sdcard/video/full_frame_camera.h264
fps       = 30
codec     = 0           # 0=H264, 1=H265

SDP 输出
───────────────────────────────────────────────────────────────────────────────
m=video 0 RTP/AVP 96
a=rtpmap:96 H264/90000
a=fmtp:96 packetization-mode=1;sprop-parameter-sets=<SPS_BASE64>,<PPS_BASE64>
a=framerate:30

🎵 音频配置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
输入文件  : full_frame_camera.pcm
格式      : PCM S16LE (Little-Endian)
采样率    : 16000 Hz
声道数    : 1 (单声道)
每包采样  : 320 (20ms @ 16kHz)

配置文件
───────────────────────────────────────────────────────────────────────────────
[audio]
file               = sim_sdcard/video/full_frame_camera.pcm
sample_rate        = 16000
channels           = 1
samples_per_packet = 320
codec              = 2     # 2=L16 (Linear PCM 16-bit, Big-Endian)

数据流转换
───────────────────────────────────────────────────────────────────────────────
┌─────────────────────────────────────────────────────────────────────────┐
│ 输入: PCM S16LE (Little-Endian)                                       │
│                                                                        │
│ AudioFileSource.cpp:146-149                                            │
│   读取文件，直接返回原始数据 (Little-Endian)                           │
│                                                                        │
│ rtsp.c:761-771                                                         │
│   检测到 L16 格式                                                      │
│   使用 htons() 转换字节序                                              │
│   输出: PCM S16BE (Big-Endian)                                        │
│                                                                        │
│ RTSP/RTP 传输 (PT=97)                                                 │
│   Payload: L16 (Big-Endian, 标准要求)                                   │
│                                                                        │
│ 客户端接收 (ffplay/ffprobe)                                           │
│   解码: pcm_s16be (Big-Endian)                                        │
│   播放: 正常                                                         │
└─────────────────────────────────────────────────────────────────────────┘

SDP 输出
───────────────────────────────────────────────────────────────────────────────
m=audio 0 RTP/AVP 97
a=rtpmap:97 L16/16000/1

实际检测
───────────────────────────────────────────────────────────────────────────────
Stream #0:0: Audio: pcm_s16be, 16000 Hz, 1 channels, s16, 256 kb/s

⚠️  注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 字节序: RTSP 标准 L16 必须是 Big-Endian
   • 输入文件: s16le (Little-Endian) ✓
   • 系统转换: htons() (Little → Big) ✓
   • 网络传输: s16be (Big-Endian) ✓
   • 客户端兼容: 标准格式 ✓

2. 视频帧率: 配置文件必须与实际文件匹配
   • 文件: 30fps → 配置: fps=30 ✓

3. 音频采样率: 配置文件必须与实际文件匹配
   • 文件: 16KHz → 配置: sample_rate=16000 ✓
