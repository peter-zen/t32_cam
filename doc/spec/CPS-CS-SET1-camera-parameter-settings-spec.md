## 1. 概述

该规范包含相机初始设置（CFG）、本机 LCD 设置、APP 设置、平台设置。

### 初始化设置

设备的初始化参数设置，用于设定工厂模式下的基础参数配置，或禁用/开启一些特定功能及选项。

### 本机 LCD 显示屏

通过自带的显示屏进行图像查看、参数设置、显示信息等。界面设计由工程师自行定义，完成功能即可。遵循下表的大致框架结构：

| 项目 | 参数 | 说明 |
| --- | --- | --- |
| 显示屏信息 | 2.4寸, ST7789V, 240*320, 8bit |  |
| 主屏页显示内容 | 实时画面、拍摄模式、时间、电量、卡容量、信号强度、设备名称 |  |
| 信息页显示内容 | PID、产品型号、产品名称、坐标位置、UPID、UPWD、信号强度、MCU版本、DSP版本 |  |
| 参数页设置内容 | 电池类型、UPID、UPWD、拍摄模式、PIR模式、触发周期、定时拍摄、设备名称、格式化卡、恢复出厂 |  |
| 操作按键 | 5+1个键值（上、下、左、右、确认，查看） |  |

### 手机 APP（NEACHI）

通过手机 Wi-Fi 连接设备热点，在 APP 上进行更详细的信息查看和设置。相机设计参见《NEACHI APP UI 设计参考》及 UI 图标包。

### 云平台（智感云平台）

设备进入工作模式后，同样可以在云端平台查看设备状态、参数设置等操作。
